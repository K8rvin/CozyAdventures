# План работ: «Лавка на перекрёстке миров»

По мотивам «Второй анализ после ответов.txt». Цель — играбельный вертикальный срез
уютной игры про заботливого хозяина волшебной лавки.

## Выбор технологий

**Браузерная игра: HTML5 + чистый JavaScript (ES-модули) + Canvas 2D, ноль зависимостей.**

Почему:
- Документ рекомендует Godot, но движок не установлен, а браузерный стек покрывает
  «ПК и в будущем мобильные» (тап/мышь, адаптивная вёрстка) без установки чего-либо.
- Ядро логики (головоломка, бой, экономика) — чистые ES-модули без DOM,
  тестируется из Node (`node --test`).
- Соло-разработка + ИИ: данные (предметы, враги, уровни) в JS-объектах/JSON,
  как советует документ — «наёмник = набор параметров».

```
game/

      solver.js       — решатель + адаптивные подсказки (свет)
      shelfPuzzle.js  — движок «Полки и товары» + решатель/подсказки
      battle.js       — тиковый автобой: статусы, отряд, отчёт
      items.js        — экипировка, 9 слотов, правило двуручного
      state.js        — состояние, экономика, экипаж, сохранения (+миграция)
    data/
      items.js        — 32 предмета двух миров
      enemies.js      — враги и боссы двух миров
      battles.js      — 12 боевых столкновений (5+босс на мир)
      puzzles.js      — 12 уровней «Тихой опушки» (свет)
      puzzlesShelf.js — 10 уровней «Средневекового дворика» (полки)
      shop.js         — ассортимент лавки и таверны
      crew.js         — спутники, питомцы, наёмники
    ui/
      app.js          — роутер экранов, топбар, тосты
      common.js       — шапка экрана, оверлей наград
      hub.js          — лавка (хаб), сцена на Canvas
      puzzleView.js   — список загадок + экран «Света и фонариков»
      shelfView.js    — экран «Полки и товары»
      battleView.js   — список походов + экран боя (лог, 1x/2x/4x, отчёт)
      equipView.js    — комната рыцаря (слоты, пояс, инвентарь)
      shopView.js     — прилавок (покупка/продажа)

  tests/              — node --test (58 тестов)
```

## Вертикальный срез (по разделу 22 документа)

- 1 механика головоломки: «Свет и фонарики» (светлячок → зеркала → фонари, не разбудить моль).
- 12 ручных уровней, отмена (Z), сброс (R), подсказки (H), несколько решений в части уровней.
- Лавка-хаб: прилавок, полка, сундук, рыцарь, магазин.
- Экипировка: все 9 слотов, правило двуручного оружия.
- Автобой: 5 боёв + 1 босс, лог, скорость 1x/2x, отчёт с советом после поражения.
- Экономика: монеты, покупка предметов, награды за головоломки, 2 расходника.
- Сохранение в localStorage.

## Этапы

- [x] Этап 0. Бумажный прототип — готов в исходном документе.
- [x] Этап 1. Ядро головоломки + решатель + 12 уровней + тесты.
- [x] Этап 2. Ядро автобоя + предметы реально влияют на бой + тесты.
- [x] Этап 3. Связка: головоломка → монеты → предмет → рыцарь → бой.
- [x] Этап 4. Хаб-лавка, экраны, уютная отрисовка (без звука — отложено).
- [x] Этап 5. Проверка целостности: 42 теста зелёные, бандл собран,
  полное прохождение среза просимулировано (все 6 боёв побеждаемы,
  баланс по винрейту: подготовленный рыцарь ~74–100%).

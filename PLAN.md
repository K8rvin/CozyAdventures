# План работ: «Лавка на перекрёстке миров»

По мотивам «Второй анализ после ответов.txt». Уютная браузерная игра про
хозяина волшебной лавки: головоломки, обустройство, команда, автобои рыцаря.
Играется и деплоится: https://k8rvin.github.io/CozyAdventures/

## Выбор технологий

**Браузерная игра: HTML5 + чистый JavaScript (ES-модули) + Canvas 2D, ноль зависимостей.**
esbuild собирает `bundle.js` (iife) — игра работает и с file://, и офлайн (PWA, sw.js).
Ядро логики (`core/`) — чистые ES-модули без DOM, тесты `node --test` (190+ зелёных).
Контент — данные в `src/data/`. CI: пуш в main → тесты → сборка → GitHub Pages.

## Архитектура (актуальная)

```
game/
  index.html, styles.css, bundle.js, sw.js (офлайн), manifest.webmanifest
  src/core/   — чистая логика: state.js, formBattle.js (поле 8×3, препятствия,
                тактики), rng.js, solver.js + движки головоломок по механике
  src/data/   — items, enemies, battles (+worlds/*.js — 12 миров), puzzles*.js
                по механикам, crew, shop, sets, trophies, achievements, wanted
  src/ui/     — app.js (роутер), hub.js (сцены-хабы + хотспоты), по view на экран
  tests/      — node --test; ui-smoke рендерит все экраны на DOM-стабе
  assets/     — только рантайм-арт по тематическим папкам; исходники и PROMPTS.md —
                в ../art-src/ (пользователь генерирует, агент режет/сжимает: *_web.jpg)
  tools/      — sim-world.mjs (баланс винрейта по мирам)
```

## Механики головоломок (13 типов, 408 уровней)

Экран «Головоломки лавки» = карточки типов (арт + прогресс X/Y), внутри —
своя нумерация и блокировка цепочкой ВНУТРИ типа. Штрафы/подсказки/отмена везде.

- **Свет и фонарики** (12) — зеркала и лучи, не разбудить моль.
- **Полки и товары** (10) — расстановка товаров по правилам.
- **Загадки Хранителя** (5) — народные загадки, Wordle-расцветка попыток.
- **Строки при свече** (5) — стихи классиков без последней строки,
  виселица-свеча (6 ступеней воска), клавиатура ЙЦУКЕН + физическая.
- **Поиск предметов** (14) — искалки по мирам (+ редактор координат).
- **Тропинки** (8) — повороты плиток, проведи зверя.
- **Чай для путника** (16) — смешивание цвета (без чисел: капли-оттенки,
  метр сходства), жар как условие заказа (minHeat), кнопка «Подать путнику»,
  сцена с артом стола/котла/чашечек.
- **Механизмы** (8) — шестерёнки, передача вращения.
- **Свечи и духи** (8) — свет по Манхэттену, духи боятся света.
- **Потоки покупателей** (8) — стрелки направляют гостей.
- **Варка зелий** (100) — рецепт по шагам, поздние — на память. Приборы:
  ступка, нож (brew_32), пипетка (brew_41), крышка (brew_51); повторы шагов
  ×N (brew_61), варианты «ИЛИ». Новые механики дебютируют по главам.
- **Карты судьбы** (12) — расклады для вечерних гостей лавки.
- **Витраж миров** (58) — пазл-перестановка осколков картины мира
  (перетаскивание/два тапа, арт = сама головоломка).

## Бой (формация 8×3)

Поле 8×3, дальность (ближний/стрелок/кастер-за-заслоном), манёвр за полхода,
тактики Защита/Баланс/Нападение, свитки и зелья с пояса, препятствия (1–2
непролазные клетки в нейтральной полосе, BFS-обход), реплей с фигурками
(магия/стрелы/стихии различаются), Конструктор боя в Мастерской.

## Прогрессия и уют

- 12 миров × походы с боссами + розыскные листы; баланс — sim-world.mjs.
- Кабинет трофеев: сцена-хаб, 12 трофеев боссов + 4 жетона розыска (арт,
  карточки с лором), ачивки «Первая полка»/«Полный кабинет».
- Команда: спутники/питомцы/наёмники (лимиты 3/2/1), кот-хранитель (гладить!),
  дневник кота, заказ дня (×2), достижения, сезоны, украшения лавки.
- Магазины по темам (оружейник/бронник/маг/алхимик), сеты предметов, крафт.

## Этапы (срез 2025) — все [x]

крафт → интерактивная лавка → 12 миров → поле 8×3 → кабинет трофеев.

### Погружение в «Загадки Хранителя» (идеи от 16.10.2026)

Общее направление — **«живые чернила на столе Хранителя»**. Правила Wordle,
100 уровней, существующий арт клавиатуры и подогнанные координаты клавиш

- [x] **1. Осязаемая клавиатура и написание букв.** Клавиша уходит вниз на
  2–3 px, получает тёплый блик и тень; нажатие на физической клавиатуре тоже
  отражается на нарисованной клавише. Буква проявляется как свежие чернила с
  лёгким растеканием и высыханием, рядом может работать перо
  (`assets/trophies/tro_keeper_quill.png`). Удаление — короткое размытие
  чернил. Для клавиш, пера и стирания — разные тихие звуки вместо общего `tap`.
- [x] **2. Проверка слова как небольшой спектакль.** Ненадолго запереть ввод и
  раскрыть вердикт слева направо (80–120 мс на букву): «на месте» — тёплое
  зеленовато-золотое свечение, «есть в ответе» — янтарное, «нет» — чернила
  бледнеют. Затем на неверной странице расплывается клякса и срабатывает
  привычное потряхивание, а попытка уходит в черновики. При победе слово
  вспыхивает золотыми чернилами, звучат шелест страницы и мурлыкание, и только
  потом появляется оверлей награды. Последовательный вердикт реализовать по
  образцу «Карт судьбы», но быстрее.

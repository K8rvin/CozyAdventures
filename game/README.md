# Лавка на перекрёстке миров

Уютная игра про заботливого хозяина волшебной лавки: решай тихие головоломки
сверху, обустраивай лавку, нанимай друзей в таверне, снаряжай рыцаря
и отправляй его в пассивные походы. По дизайн-документу
`../Второй анализ после ответов.txt`.

## Как играть

**Открой `index.html` двойным кликом** — игра собрана в `bundle.js`,
сервер не нужен. Прогресс сохраняется в браузере (localStorage).

Если хочешь через сервер: `npm run serve` → http://localhost:8080

## Что внутри

### Три мира
- **Мир 1 «Тихая опушка»** — головоломка «Свет и фонарики»: 12 уровней,
  светлячок → зеркала → фонари, не разбуди моль.
- **Мир 2 «Средневековый дворик»** — головоломка «Полки и товары»: 10 уровней
  расстановки товаров по правилам соседства (хрупкое ≠ тяжёлое, магия ≠ металл,
  зелья — рядом с травами, светящееся — на свет).
- **Мир 3 «Книжный чердак»** — головоломка «Восстановление фразы»: 10 уровней
  обмена букв на странице-змейке с кляксами. ✦ — неподвижный разделитель.
- **Поиск предметов** — 14 уровней во всех мирах: предметы уже нарисованы
  в сцене (AI-арт), искать ВСЕ экземпляры вида по названиям. Промахи не
  наказываются. Встроенный редактор хотспотов (инструмент разработчика).
- **Тропинка курьера** — 8 уровней: поворачивай плитки, проведи посылку
  от домика к дубу в обход спящих зверей.
- **Чай для путника** — 8 уровней: смешай отвар точного цвета, не перегрей котёл.
- **Механизмы и ремонт** — 8 уровней: поворачивай шестерёнки, шип↔паз,
  заведи передачу от рукояти к колокольчику.
- **Свечи и духи** — 8 уровней: ставь свечи с лимитом, освети все фонари
  и ни одного духа (стены блокируют свет).
- **Потоки покупателей** — 8 уровней: поворачивай стрелки, проведи каждого
  покупателя к его лотку без столкновений путей.

Кампания чередует все девять механик — 86 уровней. У каждой: отмена, сброс,
адаптивные подсказки на решателе, пропуск за монеты.

### Живая лавка
- **Дневник кота** 🐈: кот-хранитель записывает твои дела (загадки, покупки,
  победы) и комментирует их в хабе, спутники и питомцы болтают.
- **Питомец гуляет** по сцене лавки.
- **Заказ дня**: ежедневная загадка с двойной наградой (раз в день).
- **Достижения**: 17 трофеев, экран по 🏆 в топбаре.
- **Музыка**: генеративная лоу-фай тема лавки (WebAudio, переключатель
  в настройках), звуковые эффекты.
- **Сезоны**: отметка сезона в хабе, сезонные украшения в прилавке.

### Крафт

- **Кузница и котёл**: 12 рецептов — материалы с боёв становятся зельями
  и снаряжением (кинжал светлячка, щит стража лавки, амулет страниц…).
  Склад материалов с русскими именами и описаниями.
- Ездовой питомец удваивает добычу материалов.

### AI-генерация ассетов

Через [cleanapis API](https://cleanapis.com/) (OpenAI-совместимый) модель пишет
SVG-код — он и есть ассет: `npm run assets` генерирует баннер лавки, фоны сцен
поиска, иконку рыцаря и анимированную SMIL-заставку в `assets/`.
Ключи читаются из `../.env` (никогда не печатаются). Все ассеты опциональны:
без них игра рисует emoji/Canvas-версии. Модель задаётся `ASSET_MODEL`.

`npm run assets:variants` — сетка **3 стиля × 3 модели** (книжная акварель,
пиксель-арт, флэт-вектор) в `assets/variants/` + страница выбора
`assets/gallery.html`. Лимит ответа 120000 токенов.

### Системы
- **Экипировка**: 9 слотов, правило двуручного оружия, пояс на 2 зелья,
  42 предмета трёх ярусов (включая легендарное Перо жар-птицы за печати).
- **Два режима автобоя** (переключаются в настройках ⚙️):
  - **Сбор (поле боя)** — ряды и порядок бойцов: ближние бьют только передний
    ряд, стрелки выбирают хрупких, рассечение косит ряд. Расстановка перед
    боем, фигурки на поле, выпады, летящие стрелы, вспышки урона.
  - **Простой** — изначальный спокойный автобой с логом и карточками.
- Статусы (яд, сон, замедление, страх, щит, регенерация), скорость 1x/2x/4x,
  отчёт с советом после поражения.
- **200 боёв в 12 цепочках**: Тихая опушка, Средневековый дворик, Книжный чердак,
  Экспедиции перекрёстка, Ночной рынок, Сказочные топи, Звёздная ярмарка,
  Хрустальные горы, Пепельные степи, Нефритовый сад, Подводный грот,
  Туманные часы (финал — босс «Само Время»). 60+ существ, 50+ материалов,
  сложность растёт через множитель врагов; каждая цепочка откалибрована
  симуляцией (все 200 проходимы).
- **Таверна и конюшня**: 4 спутника (до 3 в отряде), 5 питомцев
  (бегущие/ездовые/летающие), 4 наёмника (до 2 в бою с собственными навыками).
- **Экономика**: монеты + печати мастера, магазин с растущим ассортиментом,
  материалы с боёв (ездовой питомец удваивает находки).
- **Косметика и сезонные наборы**: 6 украшений лавки (весна/лето/осень/зима),
  только красота — силу не продаём. Выставленное видно в сцене хаба.
- **Мастерская уровней**: редактор головоломок с автопроверкой решателем,
  экспорт/импорт JSON, свои уровни сохраняются в игре.
- **Звук**: крошечный WebAudio-синтезатор, переключатель на хабе.
- **Хаб-лавка**: полки заполняются товарами по мере решения загадок,
  фонарики — по мере побед.

## Управление

- Лавка — одна большая картинка: кликай по предметам (полки, прилавок, рыцарь,
  дверь, наковальня…). Паучок 🕷️ справа спускается по паутине при прокрутке.
- Тап/клик по зеркалу — повернуть; товар в лотке → клетка — поставить.
- `Z` — отмена, `H` — подсказка, `R` — сброс, `Esc` — назад, `Space` — пауза боя.

## Обучение

При первом запуске кот-хранитель 🐈 ведёт по игре прожектором: лавка,
первая головоломка, первая покупка, первый поход. Мягко и по шагам,
с кнопкой «Пропустить обучение». Показывается один раз; сброс — новая игра.

## Разработка

```bash
npm install     # один раз (esbuild для сборки)
npm test        # 65 тестов: ядро, решатели, UI-smoke, бандл
npm run build   # пересобрать bundle.js после правок src/
```

Структура: `src/core/` — чистая логика без DOM (тестируется в Node),
`src/data/` — предметы/враги/бои/уровни/экипаж/косметика как данные,
`src/ui/` — экраны. Новый уровень = объект в `src/data/puzzles*.js`;
решатель в тестах сам проверит, что он проходим и подсказки ведут к решению.

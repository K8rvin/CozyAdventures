# Лавка на перекрёстке миров

> Разработчикам и ИИ-агентам: архитектура, команды и предупреждения — в
> `../AGENTS.md`. Здесь — актуальный обзор для игрока и быстрый вход в разработку.

Уютная браузерная игра о хозяине волшебной лавки: решай головоломки, встречай
гостей, обустраивай дом, нанимай команду и снаряжай рыцаря для автобоёв.
Игра не требует аккаунта и сохраняет прогресс локально в браузере.

## Запуск

- **Двойной клик по `index.html`** — работает с `file://`, сервер не нужен.
- Через сервер: `npm run serve`, затем http://localhost:8080.
- При изменениях `src/` нужна пересборка `bundle.js`; исходный ES-модуль напрямую
  игра не загружает.

## Что внутри

### Головоломки и походы

- **838 головоломок 16 типов**: «Свет и фонарики», «Полки и товары», «Загадки
  Хранителя», «Строки при свече», поиск предметов, «Тропинки», «Чай», «Механизмы»,
  «Свечи и духи», «Потоки», «Варка зелий», «Карты судьбы», «Витраж миров»,
  «Гобелены ветров», «Подарок для гостя» и «Гости за чайным столом».
- У типов свои цепочки, отмена, сброс и подсказки. «Загадки» и «Строки» содержат
  по 100 уровней, «Карты судьбы» — 96.
- **240 боёв**: 236 в основных походах 12 миров и 4 розыскных. Перед боссом
  каждого мира есть три больших сбора из 4, 5 и 6 обычных врагов. Поле 8×3,
  расстановка отряда, тактики, препятствия, боссы 2×2 и реплей с советом.
- У каждого мира есть вступление и эпилог: 24 короткие лор-сцены со знакомыми
  гостями. Сцены показываются на пути кампании и доступны для перечитывания.
- Снаряжение занимает 9 слотов, двуручное оружие занимает обе руки, пояс вмещает
  два расходника. В таверне нанимаются спутники, питомцы и наёмники.
- В комнате можно выбрать мужской или женский образ рыцаря; это косметика,
  не влияющая на характеристики и бой.

### Первая дуга и цели

Первый запуск проводит через пролог, md_01/md_02, выбор tw_01, sk_md_01 или pp_01,
первый бой, площадь и торговый квартал, Сапоги тропинок, пчёл, Кольцо здоровья,
честный повтор и рецепт зелья лечения. При первой неудаче на пчёлах безопасный
пояс сохраняется. Обучение можно приостановить или пропустить; CTA только ведёт
к нужному месту и не выдаёт прогресс само.

После финала доступен необязательный путеводитель по 8 разделам. Дополнительная
цель накопления помогает копить на предмет, члена команды или рецепт: её статус
виден в лавке, магазинах и оверлеях наград.

### Экономика без валютной лестницы

- Только **монеты и печати мастера** — без меди, серебра и золота.
- Награды рассчитываются из нормативного времени контента и ярусов 0–5. Это
  внутренняя экономическая модель, а не таймер прохождения: повтор головоломки
  даёт около 25% базовых монет, повтор боя — около 20%.
- Печати выдаются за финалы 16 типов головоломок и первые победы над боссами.
  Заказ дня удваивает монеты, в том числе после завершения кампании.
- Пропуск не считается честным уникальным решением для достижений. Фактически
  выданные награды совпадают с отчётом на экране.
- Энергия и боевые бустеры не продаются. Платёжной или донат-кнопки в игре сейчас
  нет; косметика покупается только за внутриигровые ресурсы.

### Энергия и внесетовые находки

Запас энергии — 36, восстановление — 1 каждые два часа. Она нужна **только для
наградных повторных побед**: первые прохождения и поражения бесплатны. Обычный
повтор стоит 1, повтор босса — 3. При нехватке энергии доступна тренировка
`practice`: без монет, материалов, прогресса, pity и изменений пояса или сейва.

У 12 боссов есть личные внесетовые rare-находки. Базовый шанс — 5%, за каждую
сухую наградную победу он растёт на 2 п.п., на 12-й подходящей победе находка
гарантирована. Бонус itemFind добавляет не более 5 п.п.; pity и защита от дублей
сохраняются.

### Крафт и обмен

В кузнице и котле доступны **25 рецептов** в порядке открытия: зелья и уникальное
снаряжение. На складе 57 материалов: 45 обычных и 12 боссовских. Обменник позволяет
менять 3 обычных материала на 1 другой обычный или 1 боссовский на 2 обычных.
Получить боссовский материал обменом нельзя.

### Лавка, история и Мастерская

- Семь силуэтных хотспотов лавки повторяют предметы на фоне. Это нативные кнопки
  с клавиатурной навигацией, текстовые маршруты под сценой и доступные спрайты.
  Сцена сохраняет 3:1 даже без картинки, уважает reduced-motion; заставка intro
  показывается только в лавке.
- Площадь, торговый квартал и кабинет уже работают на v2-фонах 2400×800 с новыми
  полигонами и проверкой в Chrome; при ошибке возвращаются старые файлы и круги.
  В магазине 6 ПОЛНЫХ пакетов оформления с одиночным выбором. Старые покупки
  бесплатно объединены через aliases (carpet+crest → hearth и другие). Все фоны
  `lavka_pack_<id>_web.jpg` уже подключены в 2400×800: у каждого свои 7 хотспотов
  и позиции спрайтов по фактическому арту. При ошибке загрузки возвращаются базовая
  лавка, её геометрия и прежний sprite fallback; после успешной — legacy исчезает.
- Режим истории ведёт через круг гостей и задания. Гостевая книга содержит
  портреты, разговоры и четыре варианта каталога.
- В Мастерской есть Конструктор боя, редактор головоломок с решателем и редактор
  хотспотов искалок. Правки искалок хранятся отдельно от основного сейва.
- Кот ведёт дневник, есть достижения, трофейный кабинет, сезонные отметки,
  синтезированные звуки и необязательные тематические курсоры. Не все возможные
  изображения уже созданы: у игры есть emoji/CSS/базовые fallback.

### Книга славы

- **240 достижений** охватывают все 16 типов головоломок, 12 миров, историю,
  гостей, коллекции, особые испытания и секреты. Пять уровней редкости приносят
  очки славы — это показатель, а не валюта и не усиление.
- Карточки показывают крупные художественные медальоны, числовой прогресс и дату
  получения. Есть поиск, фильтры по разделу/редкости/состоянию и подробности по
  нажатию. Секретные условия скрыты до получения.
- Каждое новое достижение празднуется отдельной карточкой с музыкой; несколько
  наград выстраиваются в очередь и ждут окончания реплея или окна результата.
  Пропуски не считаются честными решениями, а тренировки не продвигают рекорды.

## Управление

- Мышь и касание: предметы на сценах, карточки, кнопки, перетаскивание там, где
  оно предусмотрено. Под сценами хаба есть текстовая навигация.
- `Tab` — переход между кнопками, `Enter` или `Space` — активировать.
- В головоломках: латинские `Z` — отмена, `H` — подсказка, `R` — сброс,
  `Esc` — назад. Кириллица используется для ответов; русские З/Р/К не дублируют
  команды. В бою `Space` — пауза.

## Разработка

```bash
npm install     # один раз, только dev-инструменты
npm test        # ядро, контент, решатели, UI и bundle
npm run build   # обязательно после правок src/
npm run serve   # статический сервер без генерации портрета
node tools/build-knight-visuals.mjs # обновить визуальные описания всех предметов
KNIGHT_TEST_MODE=1 node tools/knight-server.mjs # игра + generated backend в test mode
node tools/knight-server.mjs # игра + image backend, нужен GEMINI_API_KEY или OPENROUTER_API_KEY
npm run achievements:art # пересобрать медальоны (Python + Pillow, только для разработки)

node tools/sim-world.mjs nm 40 reasonable
node tools/sim-world.mjs nm 40 all
node tools/sim-economy.mjs all
node tools/sim-economy.mjs shopping
```

`sim-world` по умолчанию использует `endgame`; доступны `available`, `reasonable`,
`upgrade` и `all`. Эти профили показывают разные допущения, а не гарантированный
путь игрока. `sim-economy` сравнивает нормативные доходы и стоки: на текущем
контенте это 76 762 против 55 320 монет (отношение ≈1,39; косметика 1 310),
а печати — 62/45 ≈1,38, не обещанный баланс на все времена.

Структура: `src/core/` — чистая логика без DOM, `src/data/` — контент и настройки,
`src/ui/` — экраны, `tests/` — Node-тесты, `tools/` — симуляции и служебные
генераторы. Промты и исходники изображений — в `../art-src/`; новые полные фоны и
их интеграция выполняются только после появления реальных файлов.
